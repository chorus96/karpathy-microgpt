# 뇌 신경세포(뉴런)의 구조

이 문서는 뇌를 이루는 기본 단위인 **신경세포(뉴런, neuron)**의 구조를 정리합니다. 인공 신경망(microgpt의 `Value`·`linear`·활성화 함수)이 바로 이 생물학적 뉴런에서 영감을 받았기에, 마지막에 그 대응 관계도 함께 정리합니다.

---

## 1. 뉴런이란?

**뉴런(neuron)**은 전기·화학 신호를 통해 정보를 받아들이고, 처리하고, 다른 세포로 전달하는 신경계의 기본 단위 세포입니다. 사람의 뇌에는 약 **860억 개**의 뉴런이 있으며, 각 뉴런은 수천 개의 다른 뉴런과 연결되어 거대한 신경망을 이룹니다.

뉴런의 핵심 기능은 세 가지입니다:
1. **수용(receive)** — 다른 뉴런의 신호를 받는다
2. **통합(integrate)** — 받은 신호들을 합산해 발화 여부를 결정한다
3. **전달(transmit)** — 결정된 신호를 다음 뉴런으로 내보낸다

---

## 2. 뉴런의 기본 구조

```
   수상돌기          세포체           축삭            축삭말단
  (Dendrite)  →   (Soma)    →    (Axon)     →   (Axon Terminal)
   신호 수용        신호 통합       신호 전도        신호 전달(시냅스)
```

신호는 항상 **수상돌기 → 세포체 → 축삭 → 축삭말단**의 한 방향으로 흐릅니다.

### 2.1 세포체 (Soma / Cell Body)
뉴런의 **중심부**로, 핵(nucleus)과 미토콘드리아 등 세포 소기관이 모여 있습니다.
- 수상돌기에서 들어온 여러 신호를 **통합(합산)**합니다.
- 신호의 합이 일정 **문턱값(역치, threshold)**을 넘으면 활동전위를 발생시킵니다.
- 세포의 생명 유지와 단백질 합성을 담당합니다.

### 2.2 수상돌기 (Dendrite)
세포체에서 나뭇가지처럼 뻗어 나온 짧은 돌기들입니다.
- 다른 뉴런으로부터 신호를 **받아들이는 입력부**입니다.
- 표면에 수많은 시냅스가 있어, 한 뉴런이 수천 개의 입력을 동시에 받을 수 있습니다.
- 가지가 많을수록 더 많은 정보를 수용합니다.

### 2.3 축삭 (Axon)
세포체에서 길게 뻗어 나온 하나의 긴 섬유입니다.
- 세포체에서 만들어진 신호(**활동전위**)를 축삭말단까지 **전도(전달)**합니다.
- 길이는 수 마이크로미터에서 1미터 이상까지 다양합니다(예: 척수에서 발끝까지).
- 시작 부분인 **축삭둔덕(axon hillock)**에서 활동전위가 처음 생성됩니다.

### 2.4 미엘린 수초 (Myelin Sheath)
축삭을 감싸는 **지방질의 절연 피막**입니다.
- 신호가 새어 나가지 않게 하고 전달 속도를 크게 높입니다.
- 슈반세포(말초신경)나 희소돌기아교세포(중추신경)가 만듭니다.
- **랑비에 결절(Node of Ranvier)**: 미엘린 수초 사이의 규칙적인 틈으로, 활동전위가 결절에서 결절로 **도약 전도(saltatory conduction)**하여 속도가 빨라집니다.

### 2.5 축삭말단 (Axon Terminal / Synaptic Terminal)
축삭의 끝부분으로, 다음 뉴런과 만나는 **출력부**입니다.
- 신경전달물질(neurotransmitter)을 담은 소포(vesicle)가 모여 있습니다.
- 활동전위가 도착하면 신경전달물질을 방출합니다.

---

## 3. 시냅스 (Synapse)

한 뉴런의 축삭말단과 다음 뉴런의 수상돌기가 만나는 **연결 지점**입니다. 둘은 직접 붙어 있지 않고 아주 좁은 틈(**시냅스 틈, synaptic cleft**)으로 떨어져 있습니다.

**신호 전달 과정:**
1. 활동전위가 축삭말단에 도착
2. 신경전달물질이 시냅스 틈으로 방출됨
3. 다음 뉴런의 수용체(receptor)가 이를 받아들임
4. 받는 뉴런의 전위가 변함(흥분성 또는 억제성)

- **흥분성 시냅스(excitatory)**: 다음 뉴런을 발화시키는 쪽으로 (+)
- **억제성 시냅스(inhibitory)**: 발화를 억누르는 쪽으로 (−)

시냅스의 **연결 강도(가중치)**는 학습·경험에 따라 변합니다. 이를 **시냅스 가소성(synaptic plasticity)**이라 하며, 이것이 곧 뇌가 학습하고 기억하는 생물학적 토대입니다.

---

## 4. 신호 전달의 두 방식

| 구분 | 전기적 신호 | 화학적 신호 |
|---|---|---|
| 위치 | 뉴런 내부(축삭 등) | 뉴런 사이(시냅스) |
| 형태 | **활동전위(action potential)** | **신경전달물질** |
| 특징 | 빠르고 전부-아니면-전무(all-or-none) | 시냅스 틈을 건너 다음 세포로 |

### 활동전위 (Action Potential)
세포체에서 통합된 신호가 **문턱값(역치)**을 넘으면, 축삭을 따라 순간적으로 전위가 치솟았다 내려오는 전기 펄스가 발생합니다.
- **전부-아니면-전무 법칙**: 역치를 넘으면 항상 같은 크기로 발화하고, 못 넘으면 아예 발화하지 않습니다.
- 정보는 활동전위의 **크기**가 아니라 **빈도(초당 발화 횟수)**로 표현됩니다.

---

## 5. 뉴런의 종류

기능에 따라:
- **감각 뉴런(sensory)**: 감각기관 → 중추신경계로 신호 전달(구심성)
- **운동 뉴런(motor)**: 중추신경계 → 근육·분비샘으로 신호 전달(원심성)
- **연합 뉴런(interneuron)**: 뉴런과 뉴런을 잇는 중간 뉴런(뇌에 가장 많음)

---

## 6. 인공 신경망과의 대응 (microgpt와의 연결)

인공 뉴런(퍼셉트론)은 생물학적 뉴런을 수학적으로 단순화한 모델입니다. microgpt의 코드와 직접 대응됩니다:

| 생물학적 뉴런 | 인공 신경망 | microgpt 코드 |
|---|---|---|
| 수상돌기 (입력 수용) | 입력 벡터 `x` | 임베딩·이전 층의 출력 |
| 시냅스 연결 강도 | **가중치(weight)** | `state_dict`의 행렬 값 |
| 세포체의 신호 통합 | **가중 합(∑ wᵢxᵢ)** | `linear()` = 내적의 합 |
| 발화 문턱값(역치) | **활성화 함수** | `relu()`, `ReLU²` |
| 활동전위(발화 여부) | 활성화 출력 | 다음 층으로 전달되는 값 |
| 축삭(신호 전도) | 층 간 연결 | 다음 `linear`로의 입력 |
| 시냅스 가소성(학습) | **가중치 갱신** | `Adam` 옵티마이저의 `p.data -= ...` |

즉 microgpt의 `linear()`가 **세포체의 신호 통합(가중 합)**을, `relu()`가 **발화 문턱값**을, 학습 루프의 가중치 갱신이 **시냅스 가소성**을 흉내 냅니다. 다만 인공 뉴런은 실제 뉴런의 전기·화학적 복잡성을 극도로 단순화한 것으로, "영감을 받았을 뿐 똑같지는 않다"는 점을 기억할 필요가 있습니다.
