# 퍼셉트론(Perceptron)의 어원

이 문서는 인공 신경망의 시초가 된 **퍼셉트론(perceptron)**이라는 단어의 어원과 유래를 정리합니다.

---

## 한 줄 요약

**perceptron = perceive(지각하다) + -tron(장치)** → "**지각하는 장치(machine that perceives)**"

프랑크 로젠블랫(Frank Rosenblatt)이 1957–1958년에 만든 조어(造語)로, "인식·지각을 수행하는 기계"라는 뜻을 담았습니다.

---

## 1. 단어 분해

퍼셉트론은 두 부분의 결합입니다.

| 구성 요소 | 뜻 | 유래 |
|---|---|---|
| **percept-** | 지각하다, 인식하다 | 라틴어 *percipere* |
| **-tron** | 장치, 기계, 소자 | 그리스어 계열 접미사 |

### ① 어근 `percept-` — "지각하다"

영어 **perceive / perception**에서 왔으며, 궁극적으로는 라틴어 **percipere**에 뿌리를 둡니다.

```
per-        (완전히, 철저히)
  +
capere      (붙잡다, 취하다)
  ↓
percipere   "철저히 붙잡다 → 온전히 받아들이다 → 지각하다"
  ↓
perception  "지각, 인식"
```

- 어근 **capere**("붙잡다")는 영어 *capture*(포획), *receive*(받다), *concept*(개념)와도 같은 뿌리입니다.
- 핵심 의미는 "**감각 정보를 받아들여 인식한다**"입니다.

### ② 접미사 `-tron` — "장치·기계"

**-tron**은 20세기 과학·기술 용어에서 **장치·소자·입자**를 뜻하는 데 널리 쓰인 접미사입니다.

- 그리스어에서 도구·수단을 나타내던 요소에서 유래했습니다.
- 같은 접미사를 쓰는 단어들:
  - **electron**(전자), **cyclotron**(사이클로트론), **magnetron**(마그네트론)
  - **transistor**(트랜지스터)의 `-tor`도 비슷한 계열
- 즉 `-tron`이 붙으면 "**~을 하는 장치/기계**"라는 어감을 줍니다.

### 결합

$$\text{percept-}(\text{지각}) + \text{-tron}(\text{장치}) = \textbf{perceptron}(\text{지각하는 장치})$$

로젠블랫은 이 기계가 사람처럼 **패턴을 보고 인식(지각)**하도록 만들겠다는 포부를 이름에 담았습니다.

---

## 2. 역사적 배경

- **1943년** — 매컬러(McCulloch)와 피츠(Pitts)가 생물학적 뉴런을 논리 소자로 모델링(MCP 뉴런).
- **1957–1958년** — **프랑크 로젠블랫**이 코넬 항공 연구소에서 **퍼셉트론**을 발표. 입력에 가중치를 곱해 합한 뒤 문턱값으로 분류하는 학습 기계를 제안하고, 실제로 **Mark I Perceptron**이라는 하드웨어로 구현했습니다.
- 이름 그대로, 초기 목표는 이미지·패턴을 **지각(인식)**하는 것이었습니다(예: 도형·문자 구분).
- **1969년** — 민스키(Minsky)와 페퍼트(Papert)가 단층 퍼셉트론의 한계(XOR 문제 등)를 지적. 이후 다층 퍼셉트론(MLP)과 역전파로 이 한계가 극복되며 현대 딥러닝으로 이어집니다.

---

## 3. 개념: 퍼셉트론이 하는 일

퍼셉트론은 생물학적 뉴런을 수학적으로 단순화한 모델입니다.

$$y = f\!\left(\sum_i w_i x_i + b\right)$$

- **입력** $x_i$ 에 **가중치** $w_i$ 를 곱해 모두 더하고(가중 합),
- 편향 $b$ 를 더한 뒤,
- **활성화 함수** $f$(문턱값)로 출력을 결정합니다.

이 "가중 합 → 활성화" 구조가 곧 어원의 "지각"에 해당합니다: 여러 입력을 받아들여 하나의 판단(인식)을 내리는 것입니다.

---

## 4. microgpt와의 연결

microgpt의 신경망도 결국 퍼셉트론(인공 뉴런)을 쌓아 만든 것입니다.

| 퍼셉트론 개념 | microgpt 코드 |
|---|---|
| 가중치 $w_i$ | `state_dict`의 행렬 값 |
| 가중 합 $\sum w_i x_i$ | `linear()` (내적의 합) |
| 활성화 함수 $f$ | `relu()`, `ReLU²` |
| 다층 퍼셉트론(MLP) | `gpt()` 안의 MLP 블록(`mlp_fc1`→ReLU²→`mlp_fc2`) |

이름은 "지각하는 장치"였지만, 오늘날 그 후손인 GPT는 텍스트를 "지각"하고 다음 토큰을 예측하는 데까지 이르렀습니다.
